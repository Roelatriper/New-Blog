这篇写给**比赛、课程或机房明确要求使用 Dev-C++ 5.11** 的同学。做完后，你能在 Dev-C++ 里编译并运行一个 A+B 程序。没有指定旧版软件，若只想日常写题？直接看[小熊猫 C++](../redpanda-cpp/)更合适：操作相近，软件仍在维护。

## 1. 拿到比赛指定的安装包

先看比赛通知有没有给出安装包、版本、编译器和 C++ 标准。**有就按通知来**，不要拿网上同名的“最新版”替换。通知没有附下载地址，就向老师或赛事方要；不要从来路不明的软件站下载旧版 Dev-C++。

> **总结：**别乱来，都叫“Dev-C++”不等于环境相同。比赛指定的版本和编译器，优先级高于这篇文章。

## 2. 安装并选好编译器

1. 运行拿到的安装包。可以把程序装在简单的英文路径，例如 `C:\Dev-Cpp`。
2. 启动 Dev-C++，完成首次出现的语言、主题等设置。
3. 打开“工具 → 编译选项”，确认当前有可用的 C++ 编译器集（常见的是 TDM-GCC）；赛事指定了编译器，就选择指定的那个。
4. 若通知写了 C++11、C++14 等语言标准，按通知设置。没有要求时，先保留安装包的默认设置，跑通下面的程序即可。

> **焚决：**先选编译器，再写代码。如果编译器列表是空的，通常是安装包没带工具链；回头确认你拿到的是比赛要求的完整环境包。

## 3. 新建并运行 A+B Problem

先准备这份代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

1. 在 Dev-C++ 中选择“文件 → 新建 → 源代码”，粘贴上面的代码。
2. 保存为 `main.cpp`。请确认文件后缀是 `.cpp`，不是 `.txt`。
3. 点击工具栏的“编译运行”（或在“运行”菜单中选择同名命令）。在出现的控制台里输入 `1 2`，按回车。

看到 `3`，就说明这份程序已经在 **Dev-C++ 内完成编译和运行**。平时想再核对在线评测，可以把同一份代码提交到[洛谷 P1001](https://www.luogu.com.cn/problem/P1001)；比赛前还应在比赛指定的评测系统走一遍提交。

> **焚决：**改完代码后，要再点一次“编译运行”。否则你看到的可能是上一次生成的程序。

## 卡住时，先看这里

- **提示 `source file not compiled`：**先保存 `main.cpp`，再次编译，然后看编译日志中**第一条**报错；最后一条提示常常只是前面错误的结果。
- **窗口一闪而过：**从 Dev-C++ 里点“编译运行”，不要在文件夹里双击 `.exe`。
- **本机能跑，比赛却编译失败：**对照比赛通知检查编译器、语言标准、输入输出方式及使用的头文件。`bits/stdc++.h` 不是标准 C++ 头文件，别在不确认评测环境时依赖它。
- **想使用断点：**确认当前编译配置生成了调试信息，重新编译后再启动调试；本文不展开 Debug 操作。

需要更大范围的整数时，直接把相应变量写成 `long long`。别把 `#define int long long` 当成通用开关：放在上面代码的 `int main()` 前，它会把函数声明也替换掉，导致编译失败。

完成后，你可以回到[环境选择总指南](../cpp-environment/)，或阅读[编辑器、编译器和代码是什么关系](../toolchain-basics/)了解原理。
