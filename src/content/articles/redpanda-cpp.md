## 为什么把它放在第一推荐

如果你只想尽快开始写算法题，小熊猫 C++ 是目前最接近“下载、安装、写代码、运行”的路线。它保留了 Dev-C++ 熟悉的单文件操作，又仍在持续维护，并提供问题集、调试和代码补全等功能。

它的官方项目名是 **Red Panda C++**，源代码托管在 [royqh1979/RedPanda-CPP](https://github.com/royqh1979/RedPanda-CPP)。

如果你不明白我在说什么。我的粗略意思是：这个项目开源了，纯净无广，且有人一直在修bug，做适配。所以这个IDE适合不想折腾的你。

下载时只使用项目 README 指向的中文站、SourceForge 或 GitHub Releases，避免来源不明的二次打包版本。

> Dev-C++ 仍然会出现在课程和比赛里，所以需要认识它；日常练习时，小熊猫 C++ 更适合承担“轻量、开箱即用”这个角色。

## 安装

1. 打开[官方 GitHub 仓库](https://github.com/royqh1979/RedPanda-CPP)，进入 Releases，或者使用 README 中列出的官方下载站。
2. Windows 初学者优先选择**包含 MinGW 编译器的完整安装包**。文件名和版本会随发布更新，不要只凭旧教程中的文件名判断。
3. 保持默认安装目录即可。路径尽量只使用英文、数字和短横线，能减少旧工具链与第三方库的兼容问题。
4. 第一次启动时，让程序自动检测编译器。如果出现多个编译器集，选择安装包自带的 64 位 GCC。

## 用 A+B 验收

我们将统一使用洛谷的[P1001](https://luogu.com.cn/problem/p1001)来验证环境。

以下为样例代码：
```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

把文件保存为 `main.cpp`。后缀必须是 `.cpp`，否则编辑器可能把它当作 C 或普通文本处理。

接着执行“运行 → 编译运行”。输入 `1 2`，看到 `3` 就说明编辑器、编译器和控制台已经连通。

## 建议调整的设置

### C++ 语言标准

在编译器设置中选择比赛允许的标准。日常学习可以使用 C++17；参加比赛时，以当届规则为准。不要因为本机支持 C++23，就在只允许 C++14 的评测环境里使用新语法。

### 保存编码

源文件统一保存为 UTF-8（该死的GBK编码）。代码本身尽量不要依赖中文路径或中文文件名；输出中文时，还需要额外处理终端编码，这不属于基本环境验收范围。

### 调试信息

Debug 配置应保留 `-g`，这样断点和变量观察才能对应到源代码。正式提交算法题时，调试符号通常不会影响评测结果。

当然如果你不需要，`-g` 也可以删去，只是debug会更顺利。

## 常见问题

### 编译按钮是灰色的

先保存为 `.cpp` 文件，再检查“工具 → 选项 → 编译器集”中是否存在有效的 GCC。若安装的是不含编译器的版本，需要重新安装完整包或手动添加编译器。

### 一闪而过

在 IDE 内使用“编译运行”，不要直接双击生成的 `.exe`。控制台程序结束后，直接双击启动的窗口会立即关闭。

### 能运行但无法调试

确认当前使用 Debug 编译配置，并检查编译器集中是否同时存在 `g++.exe` 与 `gdb.exe`。
