想用一个轻量的软件写 C++ 算法题，又不想自己拼装编译器，就从小熊猫 C++ 开始。它的操作方式接近 Dev-C++；这篇带你从下载走到软件内编译运行 A+B。

## 1. 下载带编译器的版本

1. 打开[小熊猫 C++ 官方仓库](https://github.com/royqh1979/RedPanda-CPP)。下载入口以仓库 README 指向的站点为准，不要随便找第三方重新打包的安装程序。
2. Windows 初学者选**包含 MinGW/GCC 编译器的完整安装包**。如果下载页同时有不带编译器的版本，先不要选它。
3. 运行安装程序，保持默认安装位置即可。

> **焚决：**下载前只检查一件事：安装包**是否自带编译器**。选了精简包却没有另外安装 GCC，后面就找不到“编译运行”所需的工具。

## 2. 第一次打开，确认编译器

启动小熊猫 C++。让它自动检测编译器；如果弹出多个“编译器集”，选安装包自带的 **64 位 GCC**。先不用调整其他编译参数。

## 3. 在软件里编译运行 A+B

选择“文件 → 新建 → 源代码”，把下面的代码粘贴进去：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

按 `Ctrl + S`，将文件保存为 `main.cpp`。然后选择“运行 → 编译运行”。在程序的输入窗口键入 `1 2` 并按回车；看到 `3`，就说明你已经在小熊猫 C++ 里完成了第一次编译和运行。

想用在线评测再试一次？将同一份源代码提交到[洛谷 P1001](https://www.luogu.com.cn/problem/P1001)。本地看到 `3` 是本地验收；评测页面显示 Accepted 才是在线通过。

> **焚决：**写完代码先保存，再点**编译运行**。直接双击 `.exe`，窗口很可能在程序结束时立刻关闭。

## 卡住时，先看这里

- **“编译运行”是灰色的：**先确认已把文件保存为 `.cpp`。再到“工具 → 选项 → 编译器集”检查是否检测到了 GCC；如果没有，回去检查安装包是否包含编译器。
- **提示找不到编译器：**在编译器集里改选安装包自带的 64 位 GCC。仍没有候选项时，重新安装包含 MinGW/GCC 的完整包。
- **运行后没看到 `3`：**确认输入的是两个数 `1 2`，再看编译日志是否先出现错误；改过代码就重新“编译运行”。
- **想使用断点：**可以选 Debug 配置并确认安装包提供 GDB；本篇先不展开调试。

平时写题可按课程要求选择 C++ 语言标准；比赛另有规定就按比赛来。源代码建议保存为 UTF-8，路径尽量简单。想知道“编辑器”和“编译器”为什么不是一回事，再看[原理篇](../toolchain-basics/)；想换路线，回到[环境选择总指南](../cpp-environment/)。
